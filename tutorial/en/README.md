# PPUC Colorizing DMD Tutorial

A guided path through the editor, from a frame dump to a colorization a machine plays. Where the
handbook (`Help -> Handbook`) describes every control, this tutorial follows the work in the
order it is usually done and explains why each step is there. Each chapter ends with the
handbook chapters that hold the details.

Read the chapters in order the first time; later each one stands on its own.

1. [What A Colorization Is](01-what-a-colorization-is.md)
2. [Your First Project](02-your-first-project.md)
3. [Finding Your Way Around](03-finding-your-way-around.md)
4. [Painting A Frame](04-painting-a-frame.md)
5. [Selecting, Copying And Pasting](05-selecting-copying-and-pasting.md)
6. [Telling Frames Apart](06-telling-frames-apart.md)
7. [Scores And Other Changing Content](07-scores-and-other-changing-content.md)
8. [Sprites](08-sprites.md)
9. [Backgrounds And Color Rotations](09-backgrounds-and-color-rotations.md)
10. [HD](10-hd.md)
11. [Scenes](11-scenes.md)
12. [Checking Your Work](12-checking-your-work.md)
13. [Undo](13-undo.md)
14. [Publishing](14-publishing.md)

The tutorial describes ordinary projects, whose ROM frames are 128x32. Projects with 256x64 or
192x64 ROM frames work the same way on their one plane; the handbook has a chapter on each.
